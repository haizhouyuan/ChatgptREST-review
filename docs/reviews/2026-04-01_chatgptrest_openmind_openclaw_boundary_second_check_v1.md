# 2026-04-01 ChatgptREST / OpenMind / OpenClaw Boundary Second Check v1

本次 ledger 中需要 second check 的高风险条目如下：

- `C03`
  - 因为它代表一次明确的顶层叙事反转：OpenMind 变成 durable substrate，OpenClaw 变成 optional front-end。

- `C04`
  - 因为 ADR-002 会影响所有 shell 的长期设计边界，不只是某个插件实现。

- `C05`
  - 因为它与后续 public MCP / public agent 默认入口叙事存在张力，影响产品主口径。

- `C07`
  - 因为 controller objective-first 化意味着 orchestration 语义已经进入 ChatgptREST 主仓，不再只是外围适配。

- `C08`
  - 因为“多平面仓库”是后续所有治理建议的基础判断。

- `C09`
  - 因为它直接决定 coding-agent 客户端的接入默认面，影响面广。

- `C10`
  - 因为它判断 public agent 是否只是 adapter，还是新的 integrated host 入口。

- `C11`
  - 因为这是本次复盘最核心的综合解释性结论。

- `C12`
  - 因为这条结论会直接影响后续是否要开始做 retire/deprecate 工作。

- `C13`
  - 因为它是 conflict 条目，不能被当作已冻结事实。

- `G01`
  - 因为它决定是否要新增 repo-level ADR 和 authority matrix。

- `G02`
  - 因为它决定是否要给旧入口建立正式退役计划。

- `R01`
  - 因为它是治理建议，会影响后续组织方式、命名方式和可能的拆仓策略。
