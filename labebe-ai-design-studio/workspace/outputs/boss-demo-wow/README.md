# Boss Demo Wow Pack

Open `index.html` directly in a browser.

This package is the executive-facing layer on top of the Paperclip evidence:

- `index.html`: visual demo console for the 90-second boss walkthrough.
- `../boss-demo-onepager.html`: single-screen outcome board requested by Pro review.
- `../agent-handoff-map.md`: agent-to-agent decision chain.
- `../space-smart-concept-card.md`: boss-readable concept card.
- `../claim-lineage-matrix.md`: allowed and blocked market claim evidence.
- `90-second-script.md`: spoken track for the demo.
- `assets/`: local Labebe visual material reused from the design library.

Evidence remains in the parent `outputs/` directory and in `pro_requests/20260425_paperclip_labebe_demo_config_review/evidence/`.

Quality intent:

- Lead with the product story instead of the mechanics.
- Make the agent relay visible and credible.
- Keep risk gates prominent so the wow factor does not come from unsafe claims.
- Preserve all existing evidence and closed-loop checks.
