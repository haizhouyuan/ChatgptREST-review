# Action Policy

Allowed without human approval:

- Read local demo files.
- Generate local markdown, CSV, JSON, and presentation outlines under `outputs`.
- Run the local Paperclip process adapter script.
- Comment on Paperclip issues with local demo progress.

Requires human approval:

- Live web research.
- Use of real business accounts.
- External publication.
- Customer outreach.
- Paid tool usage.
- Safety, DFM, cost, compliance, or launch approval.

Disallowed in this demo:

- Real ad buys.
- Real Amazon, Meta, Google, email, ERP, or CRM account actions.
- Any use of raw secrets in generated artifacts.
