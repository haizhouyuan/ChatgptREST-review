# Archive

This directory stores raw uploads, older zip packages, duplicated web exports
and historical runtime artifacts.

Use archived files for provenance, not as current truth. Before reusing an
archived product claim, design decision or external review answer, check the
current masterplan under:

```text
planning/20260427_labebe_14day_execution/
```

New raw uploads should go under a dated folder such as:

```text
archive/YYYYMMDD/
```
