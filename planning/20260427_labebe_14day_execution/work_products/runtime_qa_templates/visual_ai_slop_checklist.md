# Visual AI-Slop Checklist

Use this as a blunt design-quality gate. Passing technical QA is not enough.

## Fail Signals

- Page could become any children's toy brand after logo swap.
- Hero image is atmospheric but does not show actual product value.
- Product cards look like stock marketplace filler.
- Typography scale feels arbitrary or template-generated.
- Page relies on beige/cream sameness without commercial contrast.
- Sections are decorative cards but not shopping decisions.
- Copy explains the website instead of helping shopper choices.
- Mobile page feels like a compressed desktop screenshot.
- PDP does not answer fit, size, use case, trust and bundle questions.
- Design references are visible as imitation rather than translated patterns.

## Required Reviewer Questions

1. What makes this specifically Labebe?
2. Which shopper mission does this page serve?
3. What product fact changes this layout?
4. Which claim is blocked or downgraded?
5. What would make a decision-maker say this is more than a generic AI website?
