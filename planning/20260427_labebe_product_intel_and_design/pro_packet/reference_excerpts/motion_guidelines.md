# Motion Guidelines

Only use motion that serves the business.

**Approved Motion Paths:**
1. Product entering a room scene (Hover/Transition)
2. Shop by Age recommendation switching
3. Cart drawer sliding
4. One SKU -> Multi-channel asset matrix expansion
5. Workflow approval timeline progression

**Tools to Reference:**
- **GSAP**: Long-scroll storytelling, asset matrix fission, room scene motion.
- **Rive**: Interactive state machines (e.g., Activity Wall, AI workflow states).
- **LottieFiles**: Micro-interactions, loading states, trust badges.
- **Motion (Framer Motion)**: React card layout animations, filter transitions, PDP gallery.

**Do NOT use:**
- Unrelated floating orbs or webGL tech spheres.
