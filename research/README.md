# Research Notes

This directory keeps design, DTC growth and AI-showoff research notes from
earlier iterations.

These files are reference inputs, not current implementation truth. Current
execution decisions are summarized in:

- `planning/20260427_labebe_14day_execution/`
- `docs/ARTIFACT_INDEX.md`
- `docs/STATUS.md`

When adding new research, create a dated subdirectory with a short source
registry and a conclusion file that separates facts, interpretations and open
questions.
