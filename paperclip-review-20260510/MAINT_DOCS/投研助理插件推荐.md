**Taxdown** 是西班牙税务问答，和美股/A股投研基本无关； **Tinman AI** 偏房贷 officer/underwriter 场景，也不是二级市场投研； **Particl Market Research** 偏电商研究，如果你研究 Shopify、Amazon sellers、消费品牌、跨境电商，它可能有用，但不是通用股票研究底座； **GovTribe** 只在美国政府合同、军工、国防、公共部门 IT 赛道才值得看。

## 五、A股是这批插件的明显短板

你截图里的 Research 插件整体更偏美股、全球公共公司、私有市场、机构新闻、政策和研究资料， **没有一个明显是专门覆盖 A股公告、A股行情、A股财务、龙虎榜、互动易、北向资金、基金持仓、研报库的插件** 。所以 A股部分不要指望只靠 Codex Research 插件解决。

A股建议另接三类数据：

**第一类：官方披露源。** 巨潮资讯网首页就有深市、沪市、北交所、基金、债券、港股、调研、发行上市等公告/数据入口，也有数据 API、智能公告、行情中心等入口；深交所官网有“信息披露/上市公司信息/定期报告/上市公司公告”等栏目；上交所官网也有“上市公司定期报告预约披露情况”和披露、监管、数据等入口。

**第二类：Python 数据库。** AKShare 是 Python 财经数据接口库，覆盖股票、期货、期权、基金、外汇、债券、指数、加密货币等基本面、实时/历史行情和衍生数据，主要用于学术研究目的；Tushare Pro 有积分和单独权限体系，A股日线、基础数据、财报等可按积分访问，分钟、新闻、公告、美股/港股等部分则需单独权限或捐助。

**第三类：自建抓取/同步层。** 例如把巨潮公告、上交所/深交所公告、AKShare/Tushare 行情、财报、互动易、基金持仓、行业指数、估值分位都落到本地 SQLite/Postgres，然后让 Codex 读你的数据库或生成日报。这样才像真正的“个人投研助理”。

## 六、按你的四个目标怎么组合

### 1\. 赛道分析

推荐组合： **Zotero + Readwise + CB Insights 试用 + Daloopa + PolicyNote + A股自建数据源**

赛道分析不是只看一个财务表，应该有一个固定框架：

```
赛道定义
→ 产业链地图
→ 需求端：TAM、渗透率、价格、客户预算
→ 供给端：产能、技术壁垒、成本曲线、竞争格局
→ 商业模式：收入确认、毛利率、资本开支、库存/应收
→ 关键 KPI
→ 可比公司池：美股 + A股 + 港股
→ 催化剂：财报、政策、产品发布、价格变动、订单、补贴、监管
→ 风险：估值、周期、政策、技术替代、竞争恶化
→ Watchlist 和监控条件
```

在插件选择上， **Zotero** 放 PDF/论文/研报， **Readwise** 放博客、newsletter、长文， **Daloopa** 拉美股核心公司 KPI， **PolicyNote** 监控政策监管， **CB Insights** 只在你需要一级市场/创业公司/创新赛道图谱时短期试用。

### 2\. 公司研究

推荐组合： **Quartr + Daloopa + Alpaca + Zotero**

美股公司研究优先用 Quartr 看业绩会、slides、filings、transcript；Daloopa 做 KPI 和财务数据；Alpaca 看股价、成交量、期权链、历史表现；Zotero 存所有原文材料。Alpaca 插件本身说明可以问历史数据、snapshots、quotes、option chain 等市场问题；Quartr 插件描述覆盖 14,500+ 公共公司、65 个市场，包含业绩会、transcripts、slides、filings、reports、event summaries，适合财务研究、投资分析和数据驱动工作流。

公司研究建议固定输出成这种模板：

```
公司研究 Memo
1. 一句话 thesis
2. 公司做什么：收入来源、客户、产品、地域
3. 关键 KPI：过去 8–12 个季度趋势
4. 财务质量：收入、毛利率、经营利润率、FCF、ROIC、负债
5. 管理层叙事变化：最近 4 次 call 的增量变化
6. 分析师问答焦点：市场最担心什么
7. 竞争对手对照：同赛道公司如何描述需求/价格/库存
8. 估值：历史分位、可比公司、情景假设
9. 催化剂：财报日、产品日、政策、价格、订单
10. 反证清单：哪些证据出现说明 thesis 错了
11. 监控条件：价格、基本面、新闻、政策、叙事、技术面
```

### 3\. “买入点”监控

这里建议你把它设计成 **监控信号** ，不是让模型直接给“买入建议”。买入点至少拆成五类信号：

```yaml
watchlist:
  - symbol: NVDA
    market: US
    thesis: "AI accelerator demand + data center capex cycle"
    data_sources:
      price: alpaca
      ir: quartr
      fundamentals: daloopa
      notes: zotero
    alerts:
      - name: "价格回到观察区"
        type: price_zone
        condition: "close <= target_watch_price"
      - name: "估值回到历史低分位"
        type: valuation_percentile
        condition: "ntm_pe_percentile <= 35"
      - name: "业绩会叙事变化"
        type: transcript_keyword_change
        keywords: ["supply constraint", "gross margin", "lead time", "capex"]
      - name: "放量反转"
        type: technical
        condition: "close > ma20 and volume > 1.8 * volume_ma20"
      - name: "反证触发"
        type: thesis_risk
        keywords: ["order pushout", "inventory correction", "pricing pressure"]

  - symbol: "300750.SZ"
    market: CN
    thesis: "动力电池全球份额 + 储能增长"
    data_sources:
      disclosure: cninfo
      price: akshare_or_tushare
      exchange: szse
    alerts:
      - name: "公告催化"
        type: announcement
        keywords: ["回购", "业绩预告", "订单", "产能", "减持", "定增"]
      - name: "财报窗口"
        type: reporting_calendar
        condition: "within_7_days_of_report"
      - name: "技术观察"
        type: technical
        condition: "close <= prior_support_zone and volume_shrinkage"
```

Alpaca 可以承担美股行情和期权链；A股行情/公告要另接 AKShare、Tushare、巨潮、交易所披露源。ChatGPT/Codex 里的插件不是天然 24x7 告警系统，真正长期运行建议用 **本地 cron / GitHub Actions / 云服务器定时任务 + 邮件/Telegram/飞书/企业微信通知** 。ChatGPT 计划页显示 Tasks 在 Plus/Pro/Business/Enterprise 可用，Free/Go 不可用；Codex 在 Free/Go 是 Limited，Plus 及以上可用或更高额度。

### 4\. 跟踪优秀机构、博主、独立投资人

截图里的 Research 插件没有直接覆盖 X/Twitter、雪球、公众号、Substack、YouTube、播客、SEC 13F 的完整方案。这里建议你自己建一个 `sources.csv` ：

```
name,type,platform,region,focus,source_url,frequency,credibility_score,notes
ARK Invest,institution,website,US,disruptive tech,,weekly,3,"观点激进，适合跟踪叙事"
Howard Marks,institution,memo,US,credit cycle,,monthly,5,"周期和风险框架"
某雪球大V,individual,xueqiu,CN,A股消费/医药,,daily,2,"只做观点源，不做事实源"
某Substack作者,individual,substack,US,semiconductor,,weekly,4,"产业链拆解强"
```

然后把来源分成三层：

```
事实源：公告、财报、交易所、SEC、业绩会、监管文件
解释源：机构研报、行业报告、专家访谈、公司访谈
观点源：博主、独立投资人、播客、newsletter、社媒
```

Readwise 负责吸收文章、newsletter、网页高亮；Zotero 负责沉淀 PDF、论文和长报告；Codex 负责每周生成“观点变化摘要”和“可验证问题清单”。Readwise 的定价页也显示它支持同步 highlights、组织标签/笔记、导出到 Notion/Obsidian 等，这对个人知识库很有帮助。

## 七、我的最终推荐清单

### 立刻装/试

1. **Alpaca** ：美股行情、历史数据、期权链、观察价提醒底座。
2. **Zotero** ：投研资料库，强烈建议作为长期知识底座。
3. **Daloopa** ：美股基本面和 KPI，免费档先覆盖 1–3 只核心公司。
4. **Quartr** ：公司研究非常强；没有 Pro 就先用免费移动端资料。
5. **Readwise** ：跟踪博主、机构 memo、newsletter，30 天内判断是否值得付费。
6. **PolicyNote** ：政策敏感赛道必备，免费 starter 足够先试。
7. **Scite / Life Science Research** ：只在你研究医药、AI、半导体、材料、生物科技时装。
8. **Binance** ：作为 crypto 风险偏好变量，可选。

### 暂时不装，除非你有机构账号

Morningstar、PitchBook、Factiva、Moody’s、MT Newswires、Third Bridge、CB Insights。它们价值很高，但更像机构付费数据源；没有账号时装了也很可能用不充分。

### 基本不用

Taxdown、Tinman AI。Particl 只在你重点研究电商/消费品牌/跨境电商时考虑。GovTribe 只在政府合同/军工/公共部门 IT 赛道考虑。Cube 只有在你已经有自己的数据仓库或财务数据表时才有价值。

**美股先用 Alpaca + Daloopa + Quartr；A股用巨潮/交易所 + AKShare/Tushare；资料用 Zotero + Readwise；监控用 watchlist.yaml + 定时脚本。**

这样比单纯“装很多插件”更接近真正能长期工作的投研助理。插件解决的是数据入口，真正的差异在于你有没有把 **赛道框架、公司模板、监控条件、反证清单、来源可信度、复盘流程** 固定下来。
