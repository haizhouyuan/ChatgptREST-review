# Paperclip Finbot Engineering Company

This is a governed `capability_lab_v1` Paperclip engineering harness for building read-only Finbot research capabilities.

It is intentionally a capability lab, not the Finbot business system:

- no Paperclip company registration by default;
- no production watchlist;
- no broker or trading API;
- no real market data refresh;
- no investment advice;
- no writes outside this repository root.

Current state: `capability_lab_v1` with dry-run production boundaries still enforced.

Primary runtime target: Kimi Code or approved runtime-lab agents, behind issue contracts, read-only evidence capture and write-scope validation.


## Capability Lab v1

This repo may now build and validate read-only Finbot capability contracts, fixture-backed tools, schemas, validators, and governed handoff packets. It still must not perform broker actions, trading, investment advice, production watchlist jobs, native MCP/skill/runtime config mutation, service registration, or writes outside its approved scope.
