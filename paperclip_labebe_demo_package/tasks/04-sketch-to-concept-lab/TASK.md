Goal: turn concept inputs into multiple reviewable design routes.

Checklist:

- Define sketch input format.
- Generate 4 concept routes.
- Create concept image prompts.
- Score brand fit.
- Select one direction for review.

Acceptance:

- Concept routes are materially different.
- Prompts include safety and manufacturability caveats.
- Selected route has brand-fit rationale and unresolved risks.
